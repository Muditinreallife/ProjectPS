# Local-only lab notes

- Backend uses SQLite under `backend/data/` only.
- Frontend API base is fixed to `http://127.0.0.1:5000/api`.
- Submitted usernames/passwords are appended to:
  - `backend/data/submissions.txt` (Notepad)
  - `backend/data/submissions.csv` (Excel)
- Start with `start.bat`. Stop with `STOP_LAB.bat`.
